# Sonaro 2.3.0

2026-11-27 · Build 7 · macOS 26+

## 简体中文

本次更新调整了音乐服务的连接方式，并改进登录与歌单加载的边界处理。

- **本机直连**：请求处理移至客户端，无需额外部署或配置服务器；登录凭据仍保存在 Keychain。
- **登录状态保护**：取消扫码、退出或重新登录后，旧请求不会覆盖当前登录状态；退出仅清除本机会话。
- **歌单分页**：缺失的歌曲详情不会导致后续分页提前结束，曲目按原始顺序展示。
- **播放检查**：兼容不同试听标记格式，不将试听片段当作完整歌曲播放。

接口适配为非官方实现，服务变更或安全验证可能影响可用性；播放仍受账号权限、地区和版权限制。

## English

This update changes how the app connects to the music service and improves login and playlist loading edge cases.

- **Direct connection**: Requests are prepared locally without an additional server. Login credentials remain in Keychain.
- **Session protection**: Outdated requests cannot overwrite the current login state after cancellation, logout or a new login. Signing out clears only the local session.
- **Playlist paging**: Missing track details no longer stop later pages from loading; tracks retain their original order.
- **Playback checks**: Different preview marker formats are supported, and previews are not treated as full tracks.

The integration is unofficial. Service changes or verification requirements may affect availability; account, regional and licensing restrictions still apply.
