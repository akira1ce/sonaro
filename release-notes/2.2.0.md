# Sonaro 2.2.0

2026-11-13 · Build 6 · macOS 26+

## 简体中文

本次更新重做了歌单详情的加载方式，并优化封面与列表的性能。

- **长歌单分页加载**：歌单详情按每页 200 首加载，滚动到底部自动取下一页，并在底部显示加载状态或失败重试；“播放全部”会先补齐完整列表再开始播放，不会只播到已加载的部分。
- **定位到正在播放**：歌单详情右下角新增悬浮按钮，点击后自动加载后续分页，直到找到当前歌曲并把它滚动到列表中央。
- **正在播放高亮**：当前歌曲只用强调色歌名标记，移除了列表里的常驻均衡器动画，播放时不再持续重绘。
- **歌曲行重设计**：整行悬浮背景，悬停时显示封面上的播放按钮和收藏心形，双击整行播放；首页、歌单、歌手、每日推荐、最近播放和搜索统一使用同一套行样式。
- **封面加载优化**：新增进程内的解码图片缓存，列表复用或回滚时首帧即显示封面；封面按 CDN 请求的 `param=NyN` 尺寸在后台降采样，列表缩略图不再持有整张大图，降低内存占用与滚动卡顿。
- **构建与签名**：`build-dmg.sh` 改用 `hdiutil` 直接生成 DMG，不再依赖 create-dmg，也不会弹出 Finder 窗口；构建时使用本机的 Apple Development 证书签名，签名固定后重装不再反复要求钥匙串密码。

## English

This update reworks how playlist details load and improves cover and list performance.

- **Paged playlist loading**: Playlist details load 200 tracks per page, fetching the next page automatically at the bottom with an inline loading or retry state. "Play all" fills in the complete track list before starting, so playback never stops at the loaded pages.
- **Locate current track**: A floating button in the bottom-right corner of a playlist loads further pages until the current track is present, then scrolls it to the centre of the list.
- **Current track highlight**: The playing song is marked only by an accent-coloured title. The always-running equalizer animation is gone, so playback no longer forces continuous redraws.
- **Redesigned song rows**: Full-row hover background, a play button on the artwork and a like heart revealed on hover, and double-click anywhere to play. Home, playlists, artists, daily recommendations, recently played and search now share one row layout.
- **Cover loading**: A process-wide decoded image cache paints a cover on the first frame when a row is reused or scrolled back. Covers are downsampled off the main thread to the CDN's `param=NyN` size, so list thumbnails no longer hold full-size bitmaps, reducing memory use and scroll hitches.
- **Build and signing**: `build-dmg.sh` now creates the DMG with `hdiutil` instead of create-dmg, so no Finder window is opened. Builds are signed with the local Apple Development identity, and the fixed signature means reinstalls no longer keep asking for the Keychain password.
