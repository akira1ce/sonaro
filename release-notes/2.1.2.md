# Sonaro 2.1.2

2026-11-12 · Build 5 · macOS 26+

## 简体中文

本次更新改善登录请求、搜索体验和迷你播放器布局。

- **设备标识持久化**：为本机生成独立的设备 ID 并保存在 Keychain，重启应用或退出账号后仍沿用同一标识；扫码请求与登录后的请求使用一致的设备 ID。
- **登录 Cookie 处理**：兼容扫码接口的 Cookie 分隔格式，检查有效登录凭据；扫码前的请求仅携带设备标识，避免混入账号 Cookie。
- **搜索优化**：输入停止 600 ms 后发起搜索，按回车可立即提交；避免同一关键词的重复请求和重复分页加载，忽略已过时的搜索响应。
- **播放器布局修复**：为底部迷你播放器预留空间，避免列表、详情页和设置页的内容被遮挡。
- **测试覆盖**：补充设备标识持久化、Cookie 合并以及搜索防抖、请求去重和分页的回归测试。

后端兼容性：NeteaseCloudMusicApiEnhanced 实例需支持读取 `cookie.deviceId`。

## English

This update improves login requests, search behavior, and the mini-player layout.

- **Persistent device identity**: Store a separate device ID in Keychain and reuse it across app launches and logout. QR login and authenticated requests use the same device ID.
- **Login cookie handling**: Support the QR endpoint's cookie separators and validate login credentials. Anonymous QR requests carry only the device identity, without account cookies.
- **Search improvements**: Search after a 600 ms typing pause, or immediately when Return is pressed. Suppress duplicate requests for the same keyword and duplicate pagination requests, and ignore stale search responses.
- **Mini-player layout fix**: Reserve bottom space so the floating mini player no longer covers content in lists, detail pages, or Settings.
- **Test coverage**: Add regression tests for device identity persistence, cookie merging, search debounce, request deduplication, and pagination.

Backend compatibility: The NeteaseCloudMusicApiEnhanced instance must honor `cookie.deviceId`.
